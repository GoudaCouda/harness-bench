# 本地工具协议服务实现任务

请在 `submission/service.py` 中完成一个 Python 3.12 服务。服务通过标准输入逐行接收 JSON-RPC 2.0 请求，并通过标准输出逐行返回唯一一条 JSON 响应。

## 必须实现的能力

1. 严格实现 `protocol_contract.json` 中声明的协议帧、`tools/list` 和 `tools/call`。
2. `contacts.search` 只查询有效联系人，不修改数据库。
3. `requests.create` 创建待处理请求，正确处理重复调用、幂等冲突、无效联系人和一次性可恢复故障。
4. 服务重启后，已经创建的请求和故障消费状态仍须保留。
5. 只允许修改运行时指定的状态数据库；不得修改 `seed.db`、联系人、策略或故障规则。

## 运行合同

1. Python 入口固定为 `python -B submission/service.py`。
2. 种子数据库路径由 `CASE09_SEED_DB` 指定，运行状态数据库路径由 `CASE09_STATE_DB` 指定。
3. 服务不得联网、读取凭据、扫描其他目录、输出调试文字或创建合同外文件。
4. 标准错误可用于简短诊断，但不得包含输入数据库内容或环境变量值。
5. 只提交 `submission/service.py`；不要保留运行产生的数据库、缓存、日志或其他文件。

验收器会从全新初态启动服务，并使用合同之外的多组参数检查协议、状态、错误恢复、重启持久化和副作用。仅针对示例值硬编码不能通过验收。
