# 销售分析工作簿任务

## 目标

1. 读取 `input/sales_records.csv` 与 `input/metric_rules.md`。
2. 在 `output/sales_analysis.xlsx` 交付一个可继续编辑的 Excel 工作簿。
3. 不得修改输入文件，最终工作区不得留下中间脚本、临时文件、额外目录或其他输出。

## 必须交付的工作表

1. `清洗明细`：保留源记录顺序和全部原始字段，增加有效性、异常原因及净销售额公式列。
2. `区域汇总`：按规则列出四个区域和合计行，订单数、数量与净销售额都必须使用可编辑公式，而不是手填汇总值。
3. `品类汇总`：按规则列出三个品类和合计行，订单数、数量与净销售额都必须使用可编辑公式。
4. `异常清单`：完整列出所有异常源记录的 CSV 行号、订单号和唯一异常原因。
5. `仪表盘`：包含标题、三个由公式引用汇总表的关键指标，以及一个引用 `区域汇总` 的原生柱形图。

## 质量要求

1. 工作簿必须是标准、无宏、无外链的 OOXML `.xlsx`，不能用图片、网页或纯文本冒充。
2. 所有要求的公式都要保留公式本身和正确的缓存值，以便用户打开后立即看到数值并继续修改。
3. 图表必须是可编辑的原生图表，系列名称、分类和数据范围必须引用指定汇总表。
4. 输入中的异常不能计入任何汇总；异常判定、字段类型、排序和公式口径以 `metric_rules.md` 为唯一依据。

## 可用工具

1. 可用 Python 标准库读取和计算 CSV。
2. 可调用只读工具 `/opt/agent-tools/spreadsheet_writer.py`，其输入协议见 `/opt/agent-tools/tool_contract.json`；工具只会按你提供的结构写工作簿，不会替你判断异常或计算正确答案。
