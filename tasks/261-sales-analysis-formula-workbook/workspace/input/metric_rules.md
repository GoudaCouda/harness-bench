# 销售分析口径

## 1. 源数据与有效性

1. CSV 第一行为表头；后续数据行号按 CSV 物理行号计数，因此第一条订单的源行号是 2。
2. 数据期固定为 2026 年第二季度；日期必须是 `YYYY-MM-DD` 且为真实存在的 2026-04-01 至 2026-06-30 日期。
3. 区域只能是 `华北`、`华东`、`华南`、`西部`；渠道只能是 `直营网`、`电商`、`渠道`。
4. 销售人员、产品、品类不得为空；品类只能是 `办公配件`、`数码配件`、`数码设备`。
5. 数量必须是正整数；单价必须大于 0；折扣率必须在 0 至 0.30（含）之间；状态必须是 `已完成`。
6. 订单号按源记录顺序判重：第一次出现可继续检查，后续重复记录属于异常。

## 2. 异常原因

1. 每条异常记录只填写一个原因，按以下优先级取第一个命中的原因：`重复订单号`、`无效日期`、`销售人员缺失`、`数量无效`、`折扣率无效`、`状态非已完成`、`区域无效`、`渠道无效`、`产品或品类无效`、`单价无效`。
2. `清洗明细` 中有效记录的 `有效性` 为 `有效`、`异常原因` 留空；异常记录的 `有效性` 为 `异常` 并填写上述原因。
3. 异常记录不得进入任何订单数、数量、净销售额或图表数据。

## 3. 清洗明细结构与公式

1. `清洗明细` 的列顺序固定为：`订单号`、`销售日期`、`区域`、`渠道`、`销售人员`、`产品`、`品类`、`数量`、`单价`、`折扣率`、`状态`、`有效性`、`异常原因`、`净销售额`。
2. 数据行顺序必须与 CSV 一致；有效日期写为 Excel 数值日期并使用日期格式，非法日期保留原始文本；数量、单价、折扣率使用数值类型。
3. 每个数据行的 `净销售额` 都必须是可编辑公式：第 2 行为 `=IF(L2="有效",ROUND(H2*I2*(1-J2),2),0)`，后续逐行相对引用；公式缓存值必须等于按两位小数四舍五入后的结果。

## 4. 汇总结构与公式

1. `区域汇总` 列为 `区域`、`有效订单数`、`销售数量`、`净销售额`；区域行顺序固定为 `华北`、`华东`、`华南`、`西部`，最后是 `合计`。
2. `品类汇总` 使用相同三项指标；品类行顺序固定为 `办公配件`、`数码配件`、`数码设备`，最后是 `合计`。
3. 非合计行必须使用 `COUNTIFS` 和 `SUMIFS`，引用 `清洗明细` 的完整数据范围与当前行标签；合计行必须使用 `SUM` 引用上方汇总行。不得把计算结果直接写成常量。
4. 公式缓存值必须与从 CSV 独立复算的订单数、数量及净销售额一致。

## 5. 异常清单与仪表盘

1. `异常清单` 列顺序固定为 `源行号`、`订单号`、`异常原因`，按源行号升序且不遗漏、不增加记录。
2. `仪表盘` 的 `B3`、`B4`、`B5` 分别用公式引用 `区域汇总` 合计行的有效订单数、销售数量和净销售额；`A3:A5` 标签依次为 `有效订单数`、`销售数量`、`净销售额`。
3. `仪表盘` 必须包含一个原生柱形图，标题为 `区域净销售额`，系列名称引用 `区域汇总!D1`，分类引用 `区域汇总!A2:A5`，数值引用 `区域汇总!D2:D5`。
4. 图表不得引用合计行，不得使用图片替代，不得包含外部链接或外部数据源。
