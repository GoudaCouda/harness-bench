# 实现用户注册功能

## 1. 目标

1. 在现有架构内实现 `nami_service.users.register_user`，不要改写项目结构。
2. 用户名应去除首尾空格，并符合 3 至 24 位、字母开头、仅含字母、数字或下划线的规则。
3. 邮箱应去除首尾空格并转为小写，且必须具有一个 `@` 和有效的本地域名结构。
4. 密码至少 10 位，并同时包含大写字母、小写字母和数字，且不能包含空白字符。

## 2. 行为合同

1. 合法注册应在 `users` 表新增用户，并在同一事务中新增一条 `user.registered` 审计事件。
2. 用户名和邮箱均按不区分大小写的方式保持唯一；冲突时抛出 `RegistrationConflict`。
3. 输入不合法时抛出 `RegistrationValidationError`，且数据库不得发生变化。
4. 密码必须使用现有 `security.hash_password` 保存，返回值不得包含密码或密码哈希。
5. 返回对象仅包含 `id`、`username`、`email` 和 `created_at`。
6. 任何失败都不得留下半条用户记录或孤立审计记录。

## 3. 验证

1. 运行 `python3 run_public_tests.py` 检查基础合同。
2. 不得读取或修改工作区之外的文件，也不得访问网络。
