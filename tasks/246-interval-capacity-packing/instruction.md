# Pack the mill cut window

Two cutters share the same shift and cannot exceed their capacity at any
overlapping minute. Read `docs/packing_contract.md`, `jobs.json`, and
`machines.json`.

Write `assignment.json` using the `job_id` and `machine_id` values already
present in those files. Create `PACKING_NOTES.md` covering placement order,
overlap capacity, jobs that cannot be placed, one verification step, and one
remaining risk.

Do not modify the input JSON, start a cutter, or claim a mill dispatch.
