# Rank mill documents

Operators need documents that mention every query term. Read
`docs/retrieval_contract.md`, `queries.json`, and every file in `corpus/`.

Write `ranking.json` using the `query_id` values from `queries.json` and the
`doc_id` names from the document filenames. Create `RETRIEVAL_NOTES.md`
covering all-term matching, tokens, ranking, one verification step, and one
remaining risk.

Do not modify the documents, contact a search cluster, or claim an index was
published.
