# Allocate mill CIDRs

`docs/ipam_contract.md`, `pool.json`, and `requests.json`.

Write `allocation.json` using the `request_id` values already present in
`requests.json`. Create `ALLOC_NOTES.md` covering prefix order, overlap,
unplaced requests, one verification step, and one remaining risk.
