# Customer Data Operations Analyst — calibration scorecard

## Must-have criteria

1. SQL joins and aggregation used in a work or substantial project setting.
2. Spreadsheet quality checks applied to operational data.
3. Customer-support operations metrics used for a decision or handoff.
4. Clear written communication demonstrated in an operational deliverable.

## Nice-to-have criteria

5. Python automation used for a repeatable data task.
6. Data-privacy handling demonstrated in a concrete workflow.

## Evidence and decision rule

- Count a criterion only when the packet describes a concrete action and work
  product or outcome. Tool lists, courses, self-ratings, and “familiar with”
  statements do not count.
- One work example may support more than one skill criterion, but it remains one
  example in `evidence_score`.
- Advance candidates with at least three supported must-haves.
- Rank by supported skill count, then distinct concrete examples, then candidate
  ID as the final deterministic tie-break.
