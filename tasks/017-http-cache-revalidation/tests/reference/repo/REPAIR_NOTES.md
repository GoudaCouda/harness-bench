# Cache revalidation repair

Stored response selection now happens before conditional evaluation: every Vary
header key must match the original request, and `Vary: *` bypasses local reuse.
After selection, If-None-Match takes precedence and compares weak entity tags,
so a tag miss never falls through to If-Modified-Since. Fixed HTTP dates are
calendar-validated; malformed client validators forward rather than creating a
false 304. The visible report was generated by calling the repaired function in
fixture order.

I ran `PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -v` from
`repo/`; both public tests passed successfully.

Remaining risk: a real adapter must combine repeated header fields without
altering commas inside entity tags and must preserve the original request
headers used to build the cache key. No origin call, purge, or deployment was
performed.
