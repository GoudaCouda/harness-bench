# 星河制造费用报销细则

文件编号：EXP-200

版本：2.0

生效日期：2026-02-01

## 第 2.3 节 出差报销时限

员工应在出差结束后 10 个自然日内提交完整报销材料。

## 第 4.2 节 采购类费用附件

单笔含税金额达到人民币 30,000 元的采购报销，必须附采购委员会在下单前出具的书面批准。

## 第 6.1 节 采购档案保存

采购合同、询价记录与审批材料的保存期限统一为 3 年，自合同关闭之日起计算。

## 第 7.1 节 电子票据

电子票据与纸质票据具有同等报销效力，但必须能通过财务系统校验真伪。

## 第 8.1 节 采购制度依据

本细则涉及采购事项时，依据《采购管理办法》v3.1 执行。
