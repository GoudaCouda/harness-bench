# Compute mill-vessel CPA

Two mill-channel vessels reported positions on a shared minute grid. Read
`docs/cpa_contract.md`, `tracks.json`, and `limit.json`.

Write `cpa.json` using the `vessel_id` values already present in the tracks.
Create `CPA_NOTES.md` covering haversine, the threshold, vessel identifiers,
one verification step, and one remaining risk.

Do not modify the tracks, contact coast radio, or claim a warning was sent.
