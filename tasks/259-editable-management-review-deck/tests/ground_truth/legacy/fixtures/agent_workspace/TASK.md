# 任务：制作第二季度经营复盘演示稿

请阅读 `input/report.md`、`input/metrics.csv` 和 `input/brand.json`，在 `output/management_review.pptx` 生成一份可供管理层直接汇报的中文演示稿。

## 交付要求

1. 使用 16:9 画布，共 6 页；每页标题直接表达该页结论。
2. 内容依次覆盖总览、区域收入、经营原因、区域行动、八周跟踪和待确认事项。
3. 报告中的关键数字必须可追溯到输入材料；允许复算完成率、差额和占比，但不得补造预测或报告外事实。
4. 所有可见文字使用 `Noto Sans SC`；文字、卡片、流程和数据图形必须是演示文稿原生可编辑对象。
5. 不得以整页图片代替页面，不得把全部文字堆在单页，不得覆盖或修改 `input/` 中的任何文件。
6. 除要求的演示文稿外，不要创建其他交付文件。
