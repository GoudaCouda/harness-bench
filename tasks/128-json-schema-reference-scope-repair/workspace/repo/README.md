# Catalog schema bundle incident

The bundle moved beneath 'https://schemas.example/catalog/'.

registry.json records retrieval URIs. A schema's '$id' changes its effective base after URI resolution. Relative '$ref' values resolve against that effective base, not the filesystem path. Fragment '#address' names an '$anchor' in the target resource.

The bundle is healthy only when:

- catalog, order, and address resources use the migrated catalog prefix;
- catalog -> order and order -> address#address both resolve;
- the valid example satisfies order/address required fields;
- the missing-address example remains invalid;
- the audit is generated by tools/check_bundle.py from current files.
