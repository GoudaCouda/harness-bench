# 工作任务

请读取 `input/` 中的固定虚构医院抬头、设备台账和巡检规范，生成 `output/monitoring_equipment_inspection_form.docx`。

## 1. 交付要求

1. 只交付一个可编辑的 Word 文档，不得创建其他输出文件。
2. 固定使用输入中的虚构医院名称、部门、表单标题、文档编号和隐私提示，不得替换成真实机构或人员信息。
3. 四台设备各占一页；每页必须准确呈现该设备的编号、名称、类型、型号、位置、责任班组和巡检周期。
4. 每台设备必须包含三项通用巡检项和两项对应设备类型的专属巡检项，顺序与规范一致。
5. 每个巡检项必须有可填写的“状态（正常/异常）”和“问题及处理记录”位置。
6. 每页必须有可填写的处理结果/复核意见、巡检人签字、复核人签字、巡检日期和复核日期区域。
7. 页面使用 A4 纵向、规范页边距和明确分页；禁止用截图、整页图片或扫描件代替可编辑表格。

## 2. 工具

1. `tools/docx_writer.py` 是已提供的离线 Word 生成工具。
2. 先按 `tools/tool_contract.json` 生成临时 JSON 规格，再调用工具输出文档；交付前删除临时规格。
3. 禁止联网、禁止修改 `input/`、`task/` 或 `tools/`，也禁止创建符号链接。
